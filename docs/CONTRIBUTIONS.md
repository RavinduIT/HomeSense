## Why this split

It maps one-to-one onto the three headings the report must cover — floor
representation, simulator operations, synchronising mechanism — so each member
owns a report section, a demo block and a viva topic that are all the same
subject.

## Commit attribution

Commits are made under each member's own git identity for the work they own, so
`git shortlog -sn --no-merges` corroborates this table rather than contradicting
it.
